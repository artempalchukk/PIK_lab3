# Лабораторна робота 3 — Qt Framework

## Варіант 1: Форма опитування «Смаки та їжа»

Qt-застосунок для проведення опитування користувача з можливістю збереження відповідей у текстовий файл.

## Функціонал

- 6 питань на тему гастрономічних вподобань
- Текстові поля для введення відповідей
- Прогрес-бар заповнення форми в реальному часі
- Валідація — перевірка що всі поля заповнені
- Збереження відповідей у `.txt` файл з датою і часом
- Можливість одразу відкрити збережений файл
- Кнопка очищення форми з підтвердженням

## Технології

- **Мова:** C++17
- **Фреймворк:** Qt 6
- **Збірка:** CMake + Ninja
- **Компілятор:** MinGW 13.1.0 (GCC)

## Структура проекту

```
lab3/
├── CMakeLists.txt
└── src/
    ├── main.cpp          — точка входу
    ├── surveydata.h      — визначення питань опитування
    ├── mainwindow.h      — оголошення головного вікна
    └── mainwindow.cpp    — реалізація UI та логіки збереження
```

## Збірка та запуск

### Вимоги
- Qt 6.2+
- CMake 3.16+

### Команди

```bash
cmake -B build -DCMAKE_PREFIX_PATH="C:/Qt/6.x.x/mingw_64"
cmake --build build --config Release
./build/Release/SurveyForm.exe
```

### Через Qt Creator

Відкрити `CMakeLists.txt` у Qt Creator і натиснути **Run** (`Ctrl+R`).

## Скріншот
